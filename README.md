# clang-format-nova

Format your code using `clang-format`. That's it. That's the extension.

## Requirements

You need `clang-format` to use `clang-format`:

```sh
brew install clang-format
```

Then, quick install from the repository:

```sh
git clone https://github.com/RahanBenabid/clang-format-nova.git

mv clang-format-nova clang-format.novaextension

open clang-format.novaextension
```

## Supported languages (even I am surprised)

C, C++, Objective-C, Objective-C++, Java, JavaScript, JSON, C#, Protobuf, TextProto, TableGen, and Verilog.

Swift is not on the list, I checked (twice)
